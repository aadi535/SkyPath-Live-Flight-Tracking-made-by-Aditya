THE PROJECT

From API response to an explorable map.

I built SkyPath to connect a Python backend with an interactive browser experience. Flask requests aircraft observations from the OpenSky Network API, checks the response and returns a small JSON feed. JavaScript turns that feed into a map and an aircraft list, using Leaflet and OpenStreetMap tiles.

Pan and zoom to explore, filter by aircraft registration country, or select an aircraft to inspect its reported altitude, speed and heading. This project demonstrates API integration, data handling, asynchronous requests, responsive interfaces and deploying a working application.

Data, honestly: OpenSky coverage and delays vary. When the service is unavailable or rate limited, SkyPath displays a clearly labelled, synthetic sample so you can still explore the interface. Sample flights are invented, not delayed live data. Registration country is not a departure location; routes and aircraft ownership are not supplied by this feed. This is an educational demo, not a navigation tool.
